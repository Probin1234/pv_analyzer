# 🎤 Presentation Skills Analyzer

Analyzes students' weekly presentation videos (face + voice, no slides) from a Google Drive folder and shows how much each student has improved from their first video to their latest.

Built for **MLA308 – NLP, Generative AI and GUI**.

See full source code in this repository.

## Setup
1. Copy `.env.example` to `.env` and add your API keys.
2. Follow the instructions in the full README for dependencies and Google Drive setup.
3. Run with `streamlit run app.py`.

**Note:** Sensitive files like `.env`, `credentials.json`, and `token.json` are gitignored and not included.
